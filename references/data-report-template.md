### 3.2 指标口径定义

| 指标名称 | 计算公式 | 说明 |
|----------|---------|------|
| 活跃用户数 (DAU) | 当日至少使用 1 次工具的用户数 | 去重统计 |
| 周活跃用户数 (WAU) | 当周至少使用 1 次工具的用户数 | 去重统计 |
| 使用率 | 活跃用户数 / 应使用总人数 × 100% | |
| 人均使用次数 | 总使用次数 / 活跃用户数 | |
| 内容采用率 | 被采纳/发布的 AI 生成内容数 / 总生成数 × 100% | 需人工标记 |
| 效率提升率 | (使用前耗时 - 使用后耗时) / 使用前耗时 × 100% | 基于抽样对比 |
